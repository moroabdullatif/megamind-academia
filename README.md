# MegaMind Academia

"Build a modern, interactive web game called MegaMind. Create a campus academic game with two main game modes:

Word Search Puzzle (interactive grid where players drag to highlight terms based on academic hints).

Term Definitions (definition given, player picks or types the correct term). Include a onboarding screen where players choose their Major (Engineering, Nursing, Science, Business, General Campus). Set up a Level progression system (Level 1, Level 2, etc.), a Coin economy (award +50 coins per win, allow spending coins on letter hints), and a Weekly Leaderboard showcasing top coin earners with a '#1 Grand MegaMind' badge.
